# 智能环境自适应旋转窗控制系统 V1.0
Smart Adaptive Rotating Window Control System

## 项目简介
本项目为嵌入式C语言控制系统，实现基于环境传感信息的旋转窗自适应闭环控制。系统采集温湿度、光照、风雨等环境参数，通过滤波算法、状态机调度、优先级决策逻辑，自动控制窗户旋转角度；同时内置故障检测、过载保护、限位保护机制，保障设备安全稳定运行。
本项目用于软件著作权申报、学科竞赛作品开发。

## 技术信息
- 开发语言：C99
- 编译方式：Makefile
- 架构：模块化分层设计（硬件抽象层HAL、传感器采集、滤波、决策调度、电机驱动、安全保护）

## 目录结构
├── include/        # 头文件，模块定义、结构体、宏配置
├── src/            # 源码实现文件
├── test/           # 主机测试、调试代码
├── Makefile        # 编译脚本
└── .gitattributes  # 换行符兼容配置

```

## 模块说明
1. `config.h`：全局参数、阈值配置
2. `sensor.h`：传感器数据采集接口
3. `filter.h`：数据滤波处理
4. `decision.h`：自适应控制决策逻辑
5. `state_machine.h`：系统状态机
6. `motor.h`：电机驱动控制
7. `safety.h`：故障检测、安全保护逻辑
8. `hal.h`：硬件抽象层，适配底层硬件

## 编译运行
```bash
make
